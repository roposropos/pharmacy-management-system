# Database files

The original source package used to prepare this public portfolio repository did not contain the final PostgreSQL schema export or demo seed data.

To make the project fully reproducible, add the database files here when they become available:

```text
database/
├── schema.sql
└── seed.sql
```

The included Polish-language project report documents the relational model, schemas, constraints, views, indexes, roles and audit-log concept in detail.
